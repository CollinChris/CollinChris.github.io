Daily System-Design Fact Bot

I wanted an excuse to run scheduled code in production, so I built a bot that teaches me system design. A GitHub Actions cron job (the free-tier scheduler) fires daily at 1pm SGT and sends one curated fact or quiz to my Telegram. Sent-state survives ephemeral runners by committing back to the repo, and when fewer than three unsent entries remain it replenishes its own content bank via the Gemini API. Typed, linted, and tested per module.

  • Python 3.12
  • uv
  • GitHub Actions
  • Telegram Bot API
  • Gemini API
  • pytest / mypy / ruff
